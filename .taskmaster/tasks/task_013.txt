Implement a component for social sharing:

```tsx
const SocialSharing = ({ event, className }) => {
  const eventUrl = typeof window !== 'undefined' 
    ? window.location.href 
    : `https://yourdomain.com/event/${event.slug}`;
  
  const title = encodeURIComponent(event.title);
  const url = encodeURIComponent(eventUrl);
  
  const trackShare = (platform) => {
    // Analytics tracking code
    console.log(`Event shared on ${platform}`, event.id);
  };
  
  return (
    <div className={`flex items-center space-x-3 ${className}`}>
      <span className="text-sm text-gray-500">Share:</span>
      
      <a
        href={`https://twitter.com/intent/tweet?text=${title}&url=${url}`}
        target="_blank"
        rel="noopener noreferrer"
        onClick={() => trackShare('twitter')}
        aria-label="Share on Twitter"
        className="text-gray-500 hover:text-blue-400 transition-colors"
      >
        <TwitterIcon className="w-5 h-5" />
        <span className="sr-only">Twitter</span>
      </a>
      
      <a
        href={`https://www.facebook.com/sharer/sharer.php?u=${url}`}
        target="_blank"
        rel="noopener noreferrer"
        onClick={() => trackShare('facebook')}
        aria-label="Share on Facebook"
        className="text-gray-500 hover:text-blue-600 transition-colors"
      >
        <FacebookIcon className="w-5 h-5" />
        <span className="sr-only">Facebook</span>
      </a>
      
      <a
        href={`https://www.linkedin.com/shareArticle?mini=true&url=${url}&title=${title}`}
        target="_blank"
        rel="noopener noreferrer"
        onClick={() => trackShare('linkedin')}
        aria-label="Share on LinkedIn"
        className="text-gray-500 hover:text-blue-700 transition-colors"
      >
        <LinkedInIcon className="w-5 h-5" />
        <span className="sr-only">LinkedIn</span>
      </a>
      
      <button
        onClick={() => {
          navigator.clipboard.writeText(eventUrl);
          trackShare('copy');
          // Show toast notification
        }}
        aria-label="Copy link to clipboard"
        className="text-gray-500 hover:text-gray-700 transition-colors"
      >
        <LinkIcon className="w-5 h-5" />
        <span className="sr-only">Copy link</span>
      </button>
    </div>
  );
};
```

# Test Strategy:
Test each sharing button to verify it opens the correct sharing URL with the proper parameters. Test the copy link functionality to ensure it copies the correct URL to the clipboard. Verify that analytics tracking functions are called when sharing options are used.
