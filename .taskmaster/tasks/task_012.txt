# Description: Create a component to display related events at the bottom of the page.
# Details:
Implement the Related Events component using the related events query:

```tsx
const RelatedEvents = async ({ eventId, category }) => {
  const relatedEvents = await getRelatedEvents(eventId);
  
  if (!relatedEvents || relatedEvents.length === 0) return null;
  
  return (
    <section className="mt-12 border-t border-gray-200 pt-8">
      <h2 className="text-2xl font-bold mb-6">Similar Events</h2>
      <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
        {relatedEvents.map(event => (
          <EventCard key={event._id} event={event} />
        ))}
      </div>
    </section>
  );
};

const EventCard = ({ event }) => {
  return (
    <Link href={`/event/${event.slug}`} className="group">
      <div className="rounded-lg overflow-hidden shadow-md hover:shadow-lg transition-shadow">
        <div className="h-40 relative">
          {event.images && event.images.length > 0 ? (
            <Image
              src={event.images[0]}
              alt={event.title}
              fill
              className="object-cover"
              sizes="(max-width: 768px) 100vw, 384px"
            />
          ) : (
            <div className="bg-gradient-to-r from-blue-500 to-purple-600 h-full w-full flex items-center justify-center text-white font-medium p-4 text-center">
              {event.title}
            </div>
          )}
          {event.category && (
            <div className="absolute top-2 left-2 bg-black bg-opacity-70 text-white text-xs px-2 py-1 rounded">
              {event.category}
            </div>
          )}
        </div>
        <div className="p-4">
          <h3 className="font-medium text-lg group-hover:text-blue-600 transition-colors">{event.title}</h3>
          <p className="text-sm text-gray-500 mt-1">
            {new Date(event.startAt).toLocaleDateString()} • {event.venue}
          </p>
        </div>
      </div>
    </Link>
  );
};
```

# Test Strategy:
Test the Related Events component with various scenarios (events with/without related events). Verify that the correct number of related events is displayed. Test the EventCard component with different event data. Check that links to related events work correctly.
